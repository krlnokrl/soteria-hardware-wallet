Bitcoin PSBT native SegWit

Unsigned PSBT (base64) from your watch-only wallet. The device shows every payment address and amount, the fee and the change, and returns the PSBT with its signatures added; load it back into the wallet, or finalize and broadcast it under Build & send.

Sparrow: Finalize Transaction for Signing, then export the PSBT (not the raw transaction hex): Save Transaction gives a .psbt file, or copy it as Base64. Tick testnet for testnet4 / testnet3 / signet wallets.

Ethereum transaction

Unsigned serialized transaction: EIP-1559 (0x02…) or legacy with EIP-155 chain id, on any EVM chain. The device shows chain, recipient, value and maximum fee – for ERC-20 transfers/approvals the token, recipient/spender and amount – and returns the signed transaction.

Tools that work with this device

  • Bitcoin watch-only wallets that create PSBTs from the descriptors (Wallet → xpubs): Sparrow (desktop, recommended), Electrum, Bitcoin Core (importdescriptors, walletcreatefundedpsbt), BlueWallet (mobile). Prefer these over websites: a watch-only xpub reveals your whole address history to whoever sees it.
  • Broadcast elsewhere: mempool.space (Bitcoin), Etherscan (Ethereum; other chains' explorers have the same page).
  • Ethereum: any tool that outputs an unsigned serialized transaction can be used with Sign → ETH transaction. The device returns the complete signed transaction (no signature to append by hand); publish it with step 3 above, an explorer's broadcast page or Foundry's cast publish.
